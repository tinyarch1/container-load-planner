# 롤 규격 데이터 규칙 (RULES.md)

대상 파일: `docs/data/rolls.csv` (가상 데이터, 실제 회사 자료 아님)

## 1. 칸
| 칸 | 형식 | 필수 |
|---|---|---|
| 제품코드 | 문자 (예: RL-0101) | 필수 |
| 롤직경 | 정수 mm | 필수 |
| 롤지폭 | 정수 mm (롤을 세웠을 때 높이) | 필수 |
| 롤수량 | 정수 개 | 필수 |
| 확인일 | YYYY-MM-DD | 필수 |
| 비고 | 문자 | 선택 (문제 데이터에는 "합성 문제데이터" 표시) |

## 2. 중복
- 같은 항목 = **제품코드가 같은 것**
- 비교 전에 맞추는 법: 앞뒤 공백 제거 + 영문 대문자로 통일 (`RL-0105 ` = `RL-0105`, `rl-0118` = `RL-0118`)
- 둘 중 남기는 것: **확인일이 최근인 것**. 확인일이 같으면 **파일에서 먼저 나온 것**을 남기고 나중 것을 뺀다.
- 제외 규칙에 걸린 줄은 중복 비교 전에 이미 빠지므로 중복으로 세지 않는다.

## 3. 정렬
- 1차: 롤직경 **큰 것부터** (내림차순)
- 2차: 직경이 같으면 제품코드 **오름차순** (대문자 기준 문자 순서)
- 빈 값은 제외 규칙으로 이미 빠지므로 정렬에는 빈 값이 없다.

## 4. 제외 (이유를 화면에 표시)
- 필수 칸 빠짐: 제품코드/롤직경/롤지폭/롤수량/확인일 중 하나라도 비어 있음
- 형식 틀림: 확인일이 YYYY-MM-DD가 아니거나 없는 날짜, 숫자 칸이 숫자가 아님
- 범위 밖: 롤직경 100~1500, 롤지폭 100~2000, 롤수량 1~100000 밖

처리 순서: 읽기 → 제외 검사 → 중복 제거 → 정렬 → 화면

## 5. 사용하는 사람에게 물었어야 할 것 (회고용)
- 같은 제품코드의 확인일이 다를 때 정말 최근 것만 맞는지, 규격이 바뀐 것인지 (현재: 최근 것 남김)
- 직경 상한 1500mm, 지폭 상한 2000mm가 실제 생산 규격을 덮는지 (현재: 임의로 정함)
